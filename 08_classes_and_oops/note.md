# JavaScript and classes

## OOP
- OOPS ek programming approach hai jisme hum code ko Objects aur Classes ke around organize karte hain, taaki code reusable, manageable aur structured ban sake.

## Object
- Collection of properties and methods
- Example: toLowerCase(), Promise(), etc

## Why use OOP-
- Code Reusability – Same code ko multiple times use karna.
- Code Organization – Data aur methods ko ek jagah organize karna.
- Encapsulation – Data ko protect karna.
- Maintainability – Code ko easily update aur manage karna.
- Inheritance – Existing code ko reuse karna.

## Parts of OOPs-
Object Literal

- Construtor Function
- Prototypes
- Classes
- Instances(new, this)

## 4 Pillars of OOPs-
- Abstraction
- Encapsulation
- Polymorphism
- Inheritance
